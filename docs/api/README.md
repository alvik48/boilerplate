# API Directory

Browse the service contracts below, or use MCP `list_apis` to discover their versions,
reference URLs and integration guides. Start with the [local health example](../integration/health.md);
the backend template does not represent a deployed business API.

## Execute a Request

Start the backend as described in the workflow, choose the explicit environment in
the playground, and press Send. Requests go from your browser directly to that
backend. A stopped backend affects execution only, not the reference or Markdown.
